# ADR-01: Выбор типа приложения

## Контекст
Однопользовательское приложение для учёта научных публикаций. Основные функции: приём файлов с данными, анализ данных, хранение в БД, экспорт данных [[BRD-V](../BRD.md#v-scope)]. Приложение должно работать на стационарных компьютерах с ОС Windows 10/11 ([BRD-VI-2](../BRD.md#vi-ограничения-и-допущения)).

## Решение
Десктопное приложение

### Статус
Принято (29.09.2026)

## Альтернативы
- **Веб-приложение** - отклонено, т. к. требует установки на сервер, к которому у Пользователя должен быть сетевой доступ, либо поднятия сервера на ПК пользователя (отдельный процесс в операционной системе, состояние которого нужно контролировать).
- **Гибридное приложение** - отклонено из-за предпочтений разработчика (необходимость использования JavaScript кроме основного языка программирования).

## Последствия
- 🟢 Локальная установка приложения, не требуется наличие сервера; работа не зависит от наличия интернета/локальной сети.
- 🔴 При необходимости добавления других пользователей потребуется существенная переработка приложения.
