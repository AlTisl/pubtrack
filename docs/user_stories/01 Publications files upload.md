# US-01: Загрузка файлов со списками публикаций

Как пользователь, я хочу загрузить файл со списком публикаций с сайта Scopus или Web of Science и просмотреть этот список, чтобы не производить парсинг данных вручную.

## Критерии приёмки
1. Приложение принимает файлы в форматах `csv` и `tsv` с заданным набором полей [[BRD-VI-3](../BRD.md#vi-ограничения-и-допущения)].
2. Если в файле нет [обязательных полей](#обязательные-поля-в-загружаемых-файлах), приложение выводит сообщение об ошибке с указанием, какие именно поля не найдены. Данные из файла при этом не загружаются.
3. Приложение корректно определяет индексатор ("Scopus" или "WoS") на основе списка полей.
4. После загрузки пользователь видит общее количество записей в файле.
5. Пользователь может просмотреть записи, указанные в п. 5, в табличном виде.
6. Если в файле обнаружены записи с некорректными значениями, или с пропущенными значениями обязательных полей - они выделяются в таблице, а пользователь получает уведомление о наличии таких записей.
7. Пользователь может сортировать записи в таблице из п. 5.
8. Пользователь может фильтровать записи в таблице из п. 5.

## Обязательные поля в загружаемых файлах
| Scopus                        | WoS | Описание                                                 |
|-------------------------------|-----|----------------------------------------------------------|
| Title                         | TI  | Название публикации                                      |
| Year                          | PY  | Год издания                                              |
| Source title                  | SO  | Название издания                                         |
| DOI                           | DI  | DOI                                                      |
| ISBN                          | BN  | ISBN                                                     |
|                               | EI  | eISSN (в Scopus отсутствует)                             |
| ISSN                          | SN  | ISSN                                                     |
| Language of Original Document | LA  | Язык публикации                                          |
| Document Type                 | DT  | Тип публикации                                           |
| Link                          | UT  | Ссылка на страницу публикации (*)                        |
| Authors                       | AF  | Список авторов                                           |
| Author(s) ID                  | RI  | Список идентификаторов авторов (Scopus ID/Researcher ID) |

(*) Поле UT в файле, полученном из Web of Science, содержит идентификаторы публикаций, используемые в т. ч. в ссылках на страницы публикаций.
