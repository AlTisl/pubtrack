# Бизнес-требования к приложению для учёта научных публикаций

## I. Цель
Сокращение затрат времени и снижение вероятности ошибок в процессе ежеквартального расчёта премии за публикации.

## II. Критерии успеха
Сокращение затрат времени на расчёт премии не менее, чем на 30 %.  
Количественные показатели для оценки снижения вероятности ошибок будут уточнены отдельно.

## III. Стейкхолдеры
- **Заказчиком** является университет <информация скрыта>.
- Требования утверждает представитель Заказчика - зав. научной библиотекой университета <информация скрыта>.
- С приложением будет взаимодействовать сотрудник научной библиотеки университета <информация скрыта>, ответственный за расчёт коэффициента премии. Установка, настройка и обслуживание приложения будет осуществляться сотрудниками университета на основе инструкций, предоставленных разработчиком, либо будет осуществляться разработчиком (по договорённости).

## IV. Существующий алгоритм
1. Пользователь получает с сайтов [Scopus](https://www.scopus.com/pages/home) и [Web of Science](https://www.webofscience.com/wos/woscc/smart-search) файлы в формате `xlsx` или `csv` со списками публикаций с начала календарного года (желаемый формат файла Пользователь указывает при выгрузке с сайта). В список включаются только публикации, где один или более авторов являются сотрудниками Заказчика.
2. Полученные в п. 1 данные Пользователь сводит в одну таблицу, добавляя столбец с указанием индексатора ("Scopus" или "WoS"). Если одна и та же публикация содержится в обоих файлах, для неё указываются оба индексатора.
3. Если в таблице, полученной в п. 2, есть записи, уже имеющиеся в аналогичных таблицах, созданных в предыдущем квартале и ранее - эти записи далее не используются (удаляются из таблицы, либо помечаются как дублирующиеся).
4. Для каждой записи в таблице Пользователь подсчитывает количество авторов и определяет, кто из авторов является сотрудником Заказчика. Это может быть реализовано, например, путём получения на сайтах [Scopus](https://www.scopus.com/pages/home) и [Web of Science](https://www.webofscience.com/wos/woscc/smart-search) файлов в формате `csv`/`tsv` со списком авторов из организации Заказчика, и последующего сравнения Scopus ID/WoS ID из этого списка с данными из списка публикаций.
5. Для каждого издания в таблице пользователь находит текущий квартиль, указанный на сайте индексатора, и вносит его в таблицу. Если запись включает два индексатора - в таблицу вносится значение квартиля, соответствующее более высокому качеству.
6. Для каждого автора из организации Заказчика Пользователь вычисляет коэффициент премии, зависящий от количества публикаций этого автора в данном квартале, количества авторов публикации и квартиля издания.

## V. Scope
1. парсинг данных из предоставляемых Пользователем файлов (списки публикаций и авторов);
2. автоматический поиск дублирующихся и дополняющих записей;
3. сопоставление авторов публикаций с сотрудниками Заказчика;
4. сохранение полученных записей;
5. экспорт данных в файл в формате `xlsx`;
6. логирование действий пользователя, приводящих к изменению сохранённых данных (запись в лог-файл).

Поиск квартилей изданий и расчёт коэффициента премии не входят в Scope, но могут быть включены в дальнейшем.

## VI. Ограничения и допущения
1. Требуется контроль действий пользователя, приводящих к изменению сохранённых данных (добавление/редактирование/удаление данных).
2. Ожидается, что приложение будет запускаться на стационарных компьютерах с ОС Windows 10/11.
3. Предполагается, что предоставляемые Пользователем файлы будут в форматах `csv` или `tsv` с кодировкой `utf-8-sig`, а также будут иметь заданную структуру (набор полей, которые должны присутствовать в файле).
4. Ожидается, что каждый год в базу данных будет добавляться до 1 тысячи новых записей.
